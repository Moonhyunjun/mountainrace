# overnight.asia — 단양 웰니스 페스티벌 콘텐츠 교체본

현재 overnight.asia(아임웹 페스티벌 템플릿)의 **레이아웃·디자인·블록 구조는 그대로 두고,
텍스트 콘텐츠만 단양 웰니스 페스티벌 내용으로 교체**한 작업본입니다.

## 파일

| 파일 | 용도 |
|---|---|
| `index.html` | 사이트 저장본(원본 HTML)에 새 문구를 그대로 반영한 확인용 사본. 위젯 구조·스타일·스크립트는 원본과 동일하고 텍스트 노드만 교체됨 (총 94개 치환, PC/모바일 블록 모두 반영) |
| `CONTENT-MAP.md` | **실제 반영용 가이드** — 아임웹 편집기에서 블록별로 어떤 문구를 어떤 문구로 바꾸면 되는지 섹션 순서대로 정리 |

## 왜 두 파일인가

아임웹 호스팅 사이트는 소스 업로드가 아니라 편집기에서 수정합니다.
따라서 실제 작업은 `CONTENT-MAP.md`를 보며 편집기에서 문구를 교체하는 방식이고,
`index.html`은 교체 결과가 어떤 모습·순서로 보이는지 확인하는 기준본입니다.

※ `index.html`은 브라우저 저장본이라 이미지·CSS 파일(`www.overnight.asia_files/`)은 포함되어 있지 않습니다.
텍스트 확인용으로만 사용하세요.
