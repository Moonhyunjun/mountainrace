# OVERNIGHT — 단양 웰니스 페스티벌 웹사이트 (overnight.asia)

overnight.asia 에 올릴 원페이지 사이트 소스입니다.
mountain-race.com 사이트와 같은 설계 원칙(PC 기준 단일 반응형 코드)을 따르며,
아임웹 원페이지 구성(고정 헤더 → 풀스크린 히어로 → 섹션 스택 → 사업자 정보 푸터)을 재현했습니다.

  장소(단양생태체육공원 · 카페산 두산활공장), WMR 2026 운영 실적.
- 푸터 사업자 정보: mountain-race.com 과 동일 —
  주식회사 앤트릭스 · 대표 문현준 · 사업자등록번호 433-81-03773 ·
  통신판매업신고 제 2026-서울강남-01255 호 · 서울특별시 강남구 선릉로 704, 10층 725호(청담빌딩).

## 파일 구성

```
overnight/
  index.html      # 원페이지 사이트 (모든 섹션)
  css/style.css   # 단일 반응형 스타일 (PC 기준 → 모바일 축소)
  js/main.js      # 모바일 메뉴, 스크롤 리빌, 숫자 카운트업, 사전알림 폼
  assets/img/     # 실제 행사/무드 사진을 넣는 폴더
```

## 운영자가 자주 바꾸게 될 것들

| 항목 | 위치 | 방법 |
|---|---|---|
| 행사 일자 | `index.html` 히어로의 `WHEN` 항목 | 단양군 협의로 일자 확정 시 "2026 개최 예정"을 실제 날짜로 교체 |
| 무드/현장 사진 | `index.html`의 `about-gallery` | `assets/img/`에 사진을 넣고 `<figure>`를 `<img src="assets/img/파일명.jpg" alt="...">`로 교체 |
| 사전알림 폼 연동 | `index.html`의 `#notifyForm` | 스티비/메일침프/구글폼 등 폼 서비스 URL을 `action`에 연결 (현재는 데모 동작) |
| 패러글라이딩 요금/신청 | `#program` 두 번째 카드 | 카페산 협의 확정 시 요금·신청 방법 기재 |
| 리조트 숙박 안내 | `#stay`의 TIER B 카드 | 리조트 협의 확정 시 객실 요금·예약 링크 기재 |
| 이용약관 · 개인정보처리방침 | 푸터 `footer-terms` | 약관 페이지 준비 후 `href` 연결 |
| 인스타그램 링크 | 히어로/푸터의 SNS 링크 | 오버나잇 전용 계정 개설 시 URL 교체 |

## 아임웹에서 쓰는 방법

현재 overnight.asia 가 아임웹으로 호스팅 중이라면 두 가지 방법이 있습니다.

1. **정적 호스팅으로 전환** — 이 폴더를 그대로 GitHub Pages / Netlify / Vercel 등에 올리고
   overnight.asia 도메인을 연결하는 방법. (권장 — 코드 전체가 그대로 반영됩니다)
2. **아임웹 안에서 콘텐츠만 교체** — 아임웹 편집기에서 기존 블록 구성을 유지한 채,
   이 `index.html`의 섹션 순서·문구를 그대로 옮겨 넣는 방법.
   섹션 순서: 히어로 → 소개(ABOUT) → 프로그램 → 타임테이블 → 숙박 → 장소 → 주최 → 사전알림.
   푸터 사업자 정보는 아임웹 [환경설정 → 기본 정보]에 위 값을 입력하면 됩니다.
