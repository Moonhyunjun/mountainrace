# 아임웹(imweb) 연동 가이드 — mountain-race.com

이 폴더에는 리포지토리의 정적 사이트(`index.html`)를 **아임웹으로 운영 중인
mountain-race.com에 그대로 붙여넣을 수 있게 변환한 코드**가 들어 있습니다.

아임웹은 FTP나 파일 업로드로 사이트를 통째로 교체할 수 없고,
아래 두 가지 방법으로만 커스텀 코드를 넣을 수 있습니다.

1. **코드 위젯** — 디자인모드에서 페이지 안에 HTML/CSS/JS 블록을 삽입
2. **헤더/푸터 코드 삽입** — 환경설정에서 사이트 전역 `<head>`/`<body>`에 코드 삽입

이 폴더의 파일은 그 제약에 맞춰 준비되어 있습니다.

## 파일 구성

| 파일 | 용도 |
|---|---|
| `widget-full.html` | 원페이지 전체(히어로·2026 리캡·레이스 안내·로드맵·장소·사전알림)를 코드 위젯 **하나**로 넣는 버전 |
| `widget-countdown.html` | 기존 아임웹 디자인은 그대로 두고 **2027 티저 배너만** 추가하는 미니 위젯 (일정 확정 전엔 COMING SOON, 날짜를 넣으면 자동으로 카운트다운) |
| `head-code.html` | (선택) 헤더 코드 삽입용 — Pretendard 폰트를 전역에서 미리 로드 |

## 적용 방법

### A. 전체 페이지를 새 디자인으로 바꾸기 (`widget-full.html`)

1. 아임웹 관리자 → **디자인모드** → 적용할 페이지로 이동
   (새 페이지를 만들어 붙인 뒤 메인으로 지정하는 방식을 추천 — 기존 페이지가 백업으로 남습니다)
2. 페이지의 기존 섹션을 비우거나, 빈 섹션을 하나 추가
3. **위젯 추가 → "코드" 위젯** 선택
4. `widget-full.html` 내용 **전체**를 복사해 붙여넣고 저장
5. 위젯이 들어간 섹션은 **여백 0 / 전체 폭(풀-와이드)** 으로 설정
   (좌우 여백이 남으면 어두운 배경 옆에 흰 띠가 보입니다)
6. 미리보기로 PC/모바일 확인 후 게시

### B. 기존 페이지에 2027 티저 배너만 추가하기 (`widget-countdown.html`)

1. 디자인모드 → 원하는 위치에 **코드 위젯** 추가
2. `widget-countdown.html` 내용 전체를 붙여넣고 저장

### C. (선택) 폰트 전역 로드 (`head-code.html`)

아임웹 관리자 → **환경설정 → SEO/헤더관리 → 헤더에 코드 삽입**에
`head-code.html` 내용을 붙여넣으면 폰트가 더 빨리 로드됩니다.
넣지 않아도 위젯은 정상 동작합니다.

## 아임웹 환경에 맞춰 바뀐 점 (원본 `index.html` 대비)

- **상단 고정 헤더/푸터 제거** — 아임웹 자체 메뉴·푸터를 그대로 사용합니다.
  아임웹 메뉴에서 섹션으로 바로 가려면 링크 주소를
  `/페이지주소#recap`, `#courses`, `#schedule`, `#venue`, `#notify` 로 걸면 됩니다.
- **모든 CSS 클래스에 `wmr-` 접두어 + `.wmr-embed` 스코프** —
  아임웹 기본 테마나 다른 위젯의 스타일과 충돌하지 않습니다.
- **JS 전역 오염 제거** — 즉시실행함수로 감싸고 임베드 내부 요소만 조작하므로
  아임웹 자체 스크립트와 간섭하지 않습니다. (중복 삽입돼도 1회만 초기화)
- **히어로 높이** — 아임웹 상단 메뉴가 따로 있는 것을 감안해
  `--wmr-hero-min` 변수(기본 `min(92svh, 900px)`)로 조절 가능합니다.

## 운영자가 자주 바꾸게 될 것들

| 항목 | 위치 | 방법 |
|---|---|---|
| 2027 대회 날짜 | 각 위젯 `<script>` 맨 위 `RACE_DATE_2027` | **확정 전에는 `null`** → COMING SOON 배너 표시. 확정되면 `new Date('2027-XX-XXT06:00:00+09:00')` 형태로 넣으면 자동으로 카운트다운 전환 |
| 2026 대회 사진 | `widget-full.html`의 `wmr-recap-gallery` | 아임웹 디자인모드에서 이미지 업로드 → 이미지 주소 복사 → `<figure>`를 `<img src="주소">`로 교체 |
| 사전알림 폼 연동 | `widget-full.html`의 사전알림 `form` | 주석 참고 — 스티비/메일침프 구독폼 코드로 교체하거나, 구글폼 `action` 연결 (현재는 데모 동작) |
| 코스/참가비 정보 | `widget-full.html`의 레이스 안내 섹션 | 2027 코스 확정 시 카드 내용 수정 |

수정 워크플로우 권장: **이 리포지토리의 파일을 먼저 고치고 → 커밋 → 아임웹 위젯에
다시 붙여넣기.** 아임웹 편집기에서만 고치면 변경 이력이 남지 않습니다.

## 주의사항

- 아임웹 **코드 위젯에서 `<script>` 사용은 요금제에 따라 제한**될 수 있습니다.
  스크립트가 동작하지 않으면 사용 중인 플랜의 "코드 삽입/외부 스크립트 허용" 여부를 확인하세요.
- 위젯을 같은 페이지에 두 번 넣지 마세요. (전체 버전과 카운트다운 버전을
  서로 다른 페이지에 넣는 것은 괜찮습니다 — 루트 id가 달라 간섭하지 않습니다)
- 아임웹 편집기가 코드를 저장하면서 일부 주석을 제거할 수 있는데, 동작에는 영향이 없습니다.
- 로컬에서 미리 보려면: `python3 -m http.server 8000` 후
  `http://localhost:8000/imweb/widget-full.html` 접속 (스타일·스크립트가 파일 안에 모두 포함되어 있어 단독으로 열립니다).
